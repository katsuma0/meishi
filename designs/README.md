# Sticker and tag designs

Cut-ready mockups for the /uses page, drawn in the site's five colours.
Each SVG is sized in real millimetres and built from filled shapes only,
one colour per vinyl layer, so they import into Cricut Design Space as
layered cut files.

| menu.svg | 76 x 50mm | indigo base, cotton text, red bar |

## Cricut notes

- Design Space sometimes imports SVGs at the wrong scale. After import,
  set the width to the millimetre size above before cutting.
- Separate layers by colour: select all, use Ungroup, then cut indigo,
  cotton (white or cream vinyl), and red as three passes.
- Text in these files uses a system font as a stand-in. Retype the text
  in a font you own in Design Space, size to match, then attach; or
  convert to paths in Inkscape (select text, Path, Object to Path) and
  re-export before importing.
- `@yourshop` in follow.svg is a placeholder; swap in the customer's
  real handle per job.
- The NFC tag (NTAG213 or NTAG215 sticker) sits behind the vinyl or
  inside a laminated stack. On a metal door or till, use an on-metal
  shielded tag or the read range drops to nothing.
- The red element is the maker's mark, the same selvedge line as the
  cards and the site. Keep it on every design.
